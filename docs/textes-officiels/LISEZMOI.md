# Textes officiels déposés à la main

Les sessions cloud ne peuvent pas ouvrir le site du ministère (voir
`docs/sources-officielles.md`). Quand une session en a besoin, Thibaud dépose ici le PDF du
texte officiel (« Add file » → « Upload files » sur GitHub), nommé d'après sa référence
(ex. `MENE2622694N.pdf`).

Ces fichiers servent à lire le texte. Le site cite toujours l'adresse officielle, jamais ce
dossier.
