# Textes officiels déposés à la main

Les sessions cloud lisent les textes officiels sur les PDF du ministère (voir
`docs/sources-officielles.md`). Quand un texte n'a pas de PDF accessible, Thibaud dépose ici
son PDF (« Add file » → « Upload files » sur GitHub), nommé d'après sa référence
(ex. `MENE2622694N.pdf`).

Ces fichiers servent à lire le texte. Le site cite toujours l'adresse officielle, jamais ce
dossier.
